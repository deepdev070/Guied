# `src/content/` — Seed Data & Curated Content

This folder stores static content definitions, seed JSON datasets, and government portal catalogs:

- **Tasks Catalog:** Base definitions of civic paperwork tasks (e.g., Driving Licence, Passport, PAN Card, Ration Card).
- **States & Union Territories:** Complete dataset of Indian states and UTs with official portal endpoints and departments.
- **Task-State Specific Data:** Verified document requirements, fee tables, eligibility rules, source links, and verification dates.
- **Database Seed Payloads:** JSON files consumed by Prisma seeding scripts (`prisma/seed.ts`).

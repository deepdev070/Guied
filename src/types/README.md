# `src/types/` — TypeScript Definitions & Interfaces

This folder contains global and domain-specific TypeScript type definitions:

- **Civic Data Models:** Interfaces for `Task`, `State`, `Step`, `DocumentItem`, `FeeItem`, `SourceCitation`.
- **API Contracts:** Standardized request/response interfaces shared between Next.js server endpoints, web client, and future Expo mobile apps.
- **UI & SEO Types:** Component prop types, layout slots, advertisement placement configs, and JSON-LD schema definitions.

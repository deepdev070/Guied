# `src/hooks/` — Custom React Hooks

This folder holds reusable client-side React hooks:

- **`useChecklist`:** Manages user progress (checked-off documents and steps) with local storage synchronization.
- **`useSearch` / `useDebounce`:** Client-side fuzzy search and debounced inputs for state and task lookup.
- **`useAdSlot` / `useIntersectionObserver`:** Lazy loading ad slot visibility tracking and impressions.
- **`useOnlineStatus`:** Network connectivity detection supporting PWA offline awareness.

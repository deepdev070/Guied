# `src/components/checklist/` — Interactive Document & Step Trackers

This folder contains core interactive paperwork checklist and workflow components:

- **Document Checklist:** Citizen checklist cards with checkboxes, original vs. photocopy markers, and download links.
- **Step-by-Step Procedure:** Ordered numbered steps with estimated completion times, fees, and actionable tips.
- **Verification Badges:** Visual tags displaying official source URL links and "Last Verified" dates (or "NEEDS VERIFICATION" flags).
- **Client Persistence:** Local state or local-storage persistence allowing users to track checked-off documents as they prepare.

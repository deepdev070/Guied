# `src/components/ui/` — Design System Primitives

This folder contains atomic, reusable design-system UI components adhering strictly to the project's design rules:

- **Theme Rules:** Strict light theme only (white and soft blue-grey surfaces, primary blue, saffron accent, success green).
- **Accessibility:** WCAG AA compliant with keyboard navigability, semantic HTML, and minimum 44px × 44px touch/tap targets.
- **Typical Components:** `Button`, `Badge`, `Card`, `Input`, `Select`, `Modal`, `Accordion`, `Callout`, `Skeleton`.

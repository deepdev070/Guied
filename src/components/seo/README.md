# `src/components/seo/` — SEO & Structured Data Components

This folder contains components and helpers dedicated to achieving Goal #1 (organic search dominance):

- **JSON-LD Schema Generators:** Standard schema markup for `HowTo`, `FAQPage`, `BreadcrumbList`, and `GovernmentPermit/Service` guides.
- **Dynamic Meta Tags:** Social sharing previews (OpenGraph, Twitter card) and canonical URL decorators.
- **Rich Snippets Support:** Markup that feeds Google search results with direct step breakdowns and fee answers.

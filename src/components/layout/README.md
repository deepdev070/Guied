# `src/components/layout/` — Layout & Structural Components

This folder contains application-wide structural shell components:

- **Header / Navigation:** Global brand header, primary navigation, search trigger, and mobile drawer.
- **Footer:** Global footer with mandatory non-government affiliation disclaimer, legal links, and sitemap links.
- **Page Shells:** Standard responsive containers, sidebars, breadcrumbs navigation, and state-selection bars.
- **Disclaimer Banner:** Persistent non-government entity notice displayed on every page.
